## 📋 Sobre o Projeto

Este projeto foi desenvolvido utilizando React e Vite, com foco em criar uma aplicação web moderna, responsiva e performática. A aplicação demonstra habilidades em desenvolvimento front-end, componentização e boas práticas de código.

🔗 **Deploy:** [https://connect-pi-umber.vercel.app](https://connect-pi-umber.vercel.app)

## 🛠️ Tecnologias Utilizadas

- **React** - Biblioteca JavaScript para construção de interfaces
- **Vite** - Build tool moderna e rápida
- **SCSS** - Pré-processador CSS para estilização avançada
- **JavaScript (ES6+)** - Linguagem de programação
- **ESLint** - Linter para garantir qualidade do código

## 🚀 Como Executar o Projeto

### Pré-requisitos

Certifique-se de ter instalado em sua máquina:
- [Node.js](https://nodejs.org/) (versão 16 ou superior)
- npm ou yarn

### Instalação

1. Clone este repositório:
```bash
git clone https://github.com/RicardoFrancoDelgado/desafio-connect-vnw.git
```

2. Acesse a pasta do projeto:
```bash
cd desafio-connect-vnw
```

3. Instale as dependências:
```bash
npm install
```

### Executando em Desenvolvimento

```bash
npm run dev
```

A aplicação estará disponível em `http://localhost:5173`

### Build para Produção

```bash
npm run build
```

### Preview da Build

```bash
npm run preview
```
